# qtng/scrolls

Scrolls: a document editor for Chữ Nôm texts in the style of old Asian documents (sections horizontal or vertical, headings, ruby, two-column text), served at `chunom.org/scrolls/`.
GitHub Pages publishes the folder `docs/` of this repository (only files in `docs/` appear on the site). Plain HTML and JavaScript with Bootstrap, no build step.
All instructions (the concept, URL rules, translation, the four sibling repositories) are in the private repository `qtng/chunom-private`, file `CLAUDE.md` and `features/scrolls/`; attach it with `add_repo` when a session starts here. Nothing technical is written in this public file.
Always: root-relative paths inside the Chunom site (`/scrolls/…`, `/chunom/js/…`), absolute URLs to qatt.org (`https://qatt.org/…`); no cache busters; interface texts with `data-vi`; tools and SQL are not here.
